# 基于FastAPI+Vue的Webshell检测平台的设计与实现 - 系统测试

## 一、测试概述

### 1.1 测试目的

验证系统在功能、接口、安全、兼容性等方面是否满足需求，重点检查：

- 各模块的增删改查是否可用，页面与数据库是否一致；
- 接口返回结构是否统一，异常分支是否给出可读提示；
- 未登录、越权、非法参数等场景是否被拦截；
- 在不同浏览器与分辨率下页面是否正常显示。

### 1.2 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11 64 位 |
| 运行环境 | Python 3.8+ |
| 数据库 | MySQL 8.0（本地 3306） |
| 浏览器 | Chrome 120 / Edge 120 |
| 接口工具 | Postman 10 |
| 后端端口 | 8080 |
| 前端端口 | 5170 |

### 1.3 测试方法

采用**黑盒测试**为主、**接口测试**为辅的方式：

- 功能测试：按模块设计正常流程与异常流程用例，手工执行；
- 接口测试：用 Postman 批量调用核心接口，核对状态码与返回结构；
- 安全测试：构造未登录、越权、SQL 注入、XSS 等请求，观察系统响应；
- 兼容性测试：在 Chrome / Edge 与不同分辨率下检查布局。

## 四、安全测试

| 测试项 | 测试方法 | 预期 | 结果 |
|------|------|------|------|
| 未登录访问 | 直接请求 `/`（不带 Token） | 返回 401 / 未登录提示 | 通 |
| 错误密码 | 输入错误密码登录 | 返回“密码错误”，不签发 Token | 通 |
| SQL 注入 | 在搜索框输入 `' OR 1=1 --` | 被参数化查询 / ORM 处理，返回空结果而非全表 | 通 |
| XSS | 在输入框提交 `<script>alert(1)</script>` | 前端转义显示为文本，不执行脚本 | 通 |
| 越权访问 | 用普通用户 Token 请求管理端接口 | 返回无权限，不返回数据 | 通 |
| 恶意文件上传 | 上传 `.jsp` / `.php` 文件 | 被扩展名白名单拦截 | 通 |
| 敏感信息 | 查看接口返回与前端源码 | 不返回密码原文、密钥 | 通 |
