# 基于FastAPI+Vue的Webshell检测平台的设计与实现 - 数据库设计

## 一、数据库概述

### 1.1 数据库选型

本系统选用 **MySQL 8.0** 作为关系型数据库，主要考虑：

- 开源免费、生态成熟，教学与生产环境都能直接使用；
- 支持事务与行级锁，适合订单、审批等需要保证一致性的场景；
- 原生支持 `utf8mb4`，可存储中文与 emoji；
- 与 FastAPI 的 ORM / 数据访问层配合成熟。

本系统共设计 **15 张业务表**，由 ORM 自动建表。

### 1.2 数据库配置

```python
SQLALCHEMY_DATABASE_URI = (
    'mysql+pymysql://root:123456@localhost:3306/webshell_platform?charset=utf8mb4'
)
```

连接串在 `config.py` / `.env` 中配置；首次启动前需先建库。

### 1.3 数据库初始化

建库脚本位于项目内的 SQL 文件，导入方式：

```sql
CREATE DATABASE IF NOT EXISTS `webshell_platform` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE `webshell_platform`;
SOURCE 01_schema.sql;
```

脚本包含 15 张表的建表语句。

## 五、数据字典

表结构中未使用枚举注释，状态字段以整型值表达，含义见各表字段说明。

| 后缀 / 前缀 | 含义 | 示例 |
|------|------|------|
| `_id` | 关联其他表主键 | `user_id`、`order_id` |
| `_time` / `_at` | 时间戳 | `create_time`、`updated_at` |
| `is_` / `has_` | 布尔标志（0/1） | `is_read`、`is_deleted` |
| `status` | 业务状态 | `status=1` 正常、`status=0` 禁用 |
