# 基于FastAPI+Vue的Webshell检测平台的设计与实现 - 系统界面展示

## 一、系统入口与端口分布

| 入口 | 地址 | 面向用户 | 技术栈 |
|------|------|------|------|
| 管理后台 | http://localhost:5170 | 管理员 | Vue 3 + Element Plus |
| FastAPI 后端 | http://localhost:8080 | — | FastAPI |

启动方式：先启动后端（8080）；再启动前端（5170）。

---

## 二、管理后台界面

### 2.1 整体布局

界面采用经典后台三栏结构：**顶部栏（系统名称 + 当前用户 + 退出） + 左侧菜单（按模块折叠） + 右侧内容区（路由视图）**。菜单项与路由表一一对应，登录后按角色加载。

### 2.2 登录页

登录页对应 `Login`，表单包含账号与密码两个必填项；提交后调用登录接口，成功后把 Token 写入本地存储并跳转首页，失败时以消息提示的形式反馈错误原因。

### 2.4 通用列表页结构

所有管理列表页遵循同一套结构：

- **搜索区**：输入框 / 下拉框 / 日期区间，条件变化后重置到第 1 页；
- **工具栏**：新增、批量删除、导出；
- **数据表格**：序号、关键业务字段、状态标签、创建时间、操作列；
- **分页器**：每页 10 / 20 / 50 条可切换。

## 四、界面设计原则

| 方面 | 做法 |
|------|------|
| 布局 | 管理端固定侧边栏 + 自适应内容区；小程序单列纵向滚动，底部 tabBar 不超过 5 项 |
| 配色 | 主色统一，状态用色区分（成功绿 / 警告橙 / 危险红），避免大面积高饱和色 |
| 反馈 | 保存、删除等操作给出即时提示；删除前二次确认；加载中显示骨架或 loading |
| 表单 | 必填项标星，失去焦点即校验，错误信息就近显示 |
| 适配 | 管理端最小宽度 1280px；小程序适配 iPhone 与主流安卓机型安全区 |
| 无障碍 | 按钮可点击区域不小于 44×44，重要图标配文字说明 |

## 五、多端协同示意

```
  ┌──────────────┐
  │   浏览器端    │
  └──────┬───────┘
         ▼
  ┌──────────────────────┐
  │  FastAPI           │
  └──────────────────────┘
```

两端共用同一套后端接口与数据库：管理端负责基础数据维护与审核，小程序端负责业务提交与查询，数据变更后另一端刷新即可看到，不存在两套数据。
